## Publish using GitHub Pages

1. Open your GitHub repository named `Rankonic`.
2. Upload **all files and folders** from this project into the repository root (not just the ZIP file).
3. Commit the uploaded files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to publish your website. The published URL will appear in the Pages settings.

## Important: set your real website URL

Before publishing, replace `YOUR-GITHUB-USERNAME` in:
- `index.html` canonical link
- `sitemap.xml`
- `robots.txt`

Use the exact GitHub Pages URL shown in **Settings → Pages**. For example, the format is `https://YOUR-GITHUB-USERNAME.github.io/Rankonic/` if the repository is named `Rankonic` and is a project site.

If you later connect a custom domain, update the canonical URL, sitemap and robots file to use that domain.

## Customize

- Edit text and page sections in `index.html` and `rankonicdigital.html`.
- Edit design in `style.css`.
- Edit mobile navigation behavior in `script.js`.
- Replace `assets/logo.svg` with your official logo if you have one.
- Add genuine case studies, testimonials and client results only when you have permission and evidence.

## Notes

This is a static website. It does not include a backend, database, quote calculator or contact form submission service. Contact buttons open WhatsApp, the phone dialer or the visitor's email application.
